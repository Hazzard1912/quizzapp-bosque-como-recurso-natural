# Imágenes del Bosque Quiz

## Instrucciones

Coloca aquí las imágenes de cada pregunta. Cada archivo debe tener **exactamente** el nombre indicado en la lista de abajo.

## Lista de archivos necesarios

| Archivo | Pregunta | Descripción sugerida |
|---------|----------|---------------------|
| `q1_bosque_propiedad.jpg` | 1 | Ilustración estilo caricatura amigable de un bosque de niebla del Valle del Cauca, mostrando un campesino con un camión de madera y un letrero que diga "¿Propiedad Privada o de la Nación?" |
| `q2_guadua_escuela.jpg` | 2 | Dibujo de un aula de escuela rural con un techo de guadua tradicional del Valle del Cauca, y unos habitantes sosteniendo una guadua de forma colaborativa |
| `q3_carretera_compensacion.jpg` | 3 | Gráfico que muestre una división de pantalla: a la izquierda una carretera en construcción (obra limpia) y a la derecha un área verde equivalente siendo reforestada con plántulas nativas |
| `q4_salvoconducto_camion.jpg` | 4 | Imagen estilo interfaz digital moderna que simule un código QR o un documento digital con el escudo de Colombia, encima del boceto de un camión transportando troncos de madera aserrada |
| `q5_plan_manejo.jpg` | 5 | Vista aérea en estilo vector de un bosque organizado en parcelas, con un especialista ambiental revisando una tableta digital frente a especies nativas como el Guayacán o el Ceiba |
| `q6_especies_vedadas.jpg` | 6 | Ilustración de una imponente Palma de Cera del Quindío/Valle junto a un Cedro, rodeados por una cinta de seguridad amarilla que diga "ESPECIE PROTEGIDA - VEDA" |
| `q7_quema_prohibida.jpg` | 7 | Dibujo en tono de alerta que muestre los cerros de Cali con un conato de incendio forestal, y un símbolo de prohibido (círculo rojo con línea diagonal) sobre unos fósforos encendidos |
| `q8_psa_bosque.jpg` | 8 | Ilustración que muestre a un campesino feliz recibiendo un incentivo simbólico (como una moneda con una hoja grabada) mientras señala un bosque frondoso del cual brota un río limpio |

## Formatos soportados
- JPG, PNG, WebP
- Tamaño recomendado: 800x600px o similar (16:9 o 4:3)
- Peso recomendado: < 500KB por imagen para carga rápida

## Nota importante
Si una imagen no existe, el componente la ocultará automáticamente sin romper la app. Puedes ir agregando las imágenes de a poco y el juego seguirá funcionando.

## Ubicación
Las imágenes deben estar en esta carpeta:
```
public/images/
```

Y se referencian en el código como:
```
/images/nombre-del-archivo.jpg
```
